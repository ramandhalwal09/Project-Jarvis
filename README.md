# Project-Jarvis
Python-based voice assistant with speech recognition and automation features.


## Features
- Voice Recognition
- Text-to-Speech
- Open Websites
- Play Music
- Fetch News Headlines

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- pygame
- requests

## How to Run
1. Install required libraries
2. Run main.py
